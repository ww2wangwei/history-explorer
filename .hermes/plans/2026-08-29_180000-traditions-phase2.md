# 全传统板块二期实施计划

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 给全传统板块加详情弹窗，每个子分类数据从 3-4 条补到 6-8 条，总数 39 → 80+ 条；详情弹窗展示完整内容（摘要 + 详版 + 关键人物 + 相关朝代）。

### Task 2: TraditionDetailDialog 组件

**Objective:** 创建点击 Tradition 卡 → 弹出的全屏弹窗，展示完整内容。

**Files:**
- Create: `src/components/Traditions/TraditionDetailDialog.tsx`

**Step 1:** 写组件，参考 `MythologyDetailDialog` 风格，复用 `ModalShell`：

```tsx
/**
 * TraditionDetailDialog — 全传统详情弹窗
 *
 * 点击 TraditionsOverview 卡片 → 弹出此全屏对话框。
 * 内容：大封面图 + 标题 + 摘要 + fullContent 详版 + 关键人物 + 朝代。
 */
import ModalShell from '@/components/ui/Modal'
import { bingImage } from '@/utils/geoImage'
import { type TraditionItem } from '@/data/traditions'

interface Props {
  item: TraditionItem | null
  onClose: () => void
}

const CATEGORY_LABEL: Record<string, { label: string; color: string }> = {
  history:    { label: '历史',     color: '#c89a5b' },
  family:     { label: '家',       color: '#d4856a' },
  myth:       { label: '神话',     color: '#a07050' },
  philosophy: { label: '哲学',     color: '#9b7eb6' },
  script:     { label: '文字',     color: '#5b9bc8' },
  literature: { label: '文学',     color: '#c89a8a' },
  art:        { label: '艺术',     color: '#e879b9' },
  calendar:   { label: '历法节气', color: '#9bc89a' },
  ritual:     { label: '礼仪制度', color: '#d4a85b' },
  food:       { label: '衣食',     color: '#b85450' },
  housing:    { label: '住行',     color: '#5bc89a' },
  tech:       { label: '科技',     color: '#5b9bc8' },
}

export default function TraditionDetailDialog({ item, onClose }: Props) {
  if (!item) return null
  const cat = CATEGORY_LABEL[item.category] ?? { label: item.category, color: '#888' }
  const bgUrl = bingImage(item.imageKeyword ?? `${item.title} ${item.era ?? ''} Chinese tradition`, 1200, 600)
  // 详版 fallback 到 summary
  const detail = item.fullContent ?? item.summary

  return (
    <ModalShell
      isOpen={!!item}
      onClose={onClose}
      className="p-2 sm:p-4"
      innerClassName="max-w-4xl"
      innerStyle={{ background: 'rgb(15, 14, 12)' }}
      ariaLabel={`${item.title} · 详情`}
    >
      <div className="relative">
        {/* 大封面图 */}
        <div className="relative h-48 sm:h-64 bg-ink-900 overflow-hidden">
          <img
            src={bgUrl}
            alt={item.title}
            className="absolute inset-0 w-full h-full object-cover"
            loading="lazy"
          />
          {/* 顶部轻、底部重的暗色蒙版 */}
          <div
            aria-hidden
            className="absolute inset-0 pointer-events-none"
            style={{
              background: 'linear-gradient(180deg, rgba(0,0,0,0.30) 0%, rgba(0,0,0,0.05) 40%, rgba(0,0,0,0.92) 100%)',
            }}
          />
          {/* 顶部子分类徽章 */}
          <div className="absolute top-3 left-3 z-10">
            <span
              className="text-xs px-2 py-0.5 rounded font-medium backdrop-blur"
              style={{ background: cat.color + '30', color: '#fdf8f0', border: `1px solid ${cat.color}80` }}
            >
              {cat.label}
            </span>
          </div>
          {/* 标题 */}
          <div className="absolute bottom-0 left-0 right-0 p-6 z-10 text-bone">
            <h2 className="font-serif text-3xl sm:text-4xl tracking-wide drop-shadow mb-1">{item.title}</h2>
            {item.era && (
              <div className="text-sm text-bone/80 tabular-nums drop-shadow">{item.era}</div>
            )}
          </div>
        </div>

        {/* 内容区 */}
        <div className="p-6 sm:p-8 space-y-5 text-sm leading-relaxed text-bone/90">
          {/* 摘要 */}
          <div className="text-base text-bone leading-relaxed border-l-2 pl-3 italic"
            style={{ borderLeftColor: cat.color }}>
            {item.summary}
          </div>

          {/* 完整内容（详版） */}
          <div className="space-y-3 text-bone/85">
            {detail.split(/[。！？]/).filter(s => s.trim()).map((para, i) => (
              <p key={i}>{para.trim()}。</p>
            ))}
          </div>

          {/* 关键人物 */}
          {item.figure && (
            <div className="pt-4 border-t border-ink-700">
              <div className="text-xs text-ink-400 uppercase tracking-wider mb-2">关键人物</div>
              <div className="text-base text-vermilion-300 font-serif">{item.figure}</div>
            </div>
          )}

          {/* 数据源说明 */}
          <div className="text-xs text-ink-400 italic pt-4 border-t border-ink-700">
            💡 在 TraditionsOverview 中浏览更多「{cat.label}」子分类
          </div>
        </div>
      </div>
    </ModalShell>
  )
}
```

**Step 3:** 修改卡片的 `onClick`：从无 → 改为 `setSelectedId(t.id)`。卡片按钮需要从 `<div>` 改成 `<button>` 或保留 `<div>` 加 `role="button" onClick`。

**当前卡片 div**（line 113-118）：
```tsx
<div
  key={t.id}
  className="relative rounded-lg overflow-hidden border ..."
  style={{ ... }}
>
```

改成加 `role="button"` `tabIndex={0}` `onClick` `onKeyDown`：

```tsx
<div
  key={t.id}
  role="button"
  tabIndex={0}
  onClick={() => setSelectedId(t.id)}
  onKeyDown={(e) => { if (e.key === 'Enter' || e.key === ' ') setSelectedId(t.id) }}
  className="relative rounded-lg overflow-hidden border ... cursor-pointer focus:outline-none focus:ring-2 focus:ring-emerald-500/60"
  style={{ ... }}
>
```

**Step 4:** 在组件最末尾 JSX 里（在 `</OverviewLayout>` 之前）渲染弹窗：

```tsx
<TraditionDetailDialog
  item={selectedItem}
  onClose={() => setSelectedId(null)}
/>
```

**Step 5:** 修改 ESC handler——如果弹窗打开，ESC 优先关闭弹窗，否则关闭 OverviewLayout：

```tsx
useEffect(() => {
  if (!isActive) return
  const handler = (e: KeyboardEvent) => {
    if (e.key === 'Escape') {
      e.stopPropagation()
      if (selectedId) setSelectedId(null)  // 弹窗优先
      else onClose()
    }
  }
  window.addEventListener('keydown', handler, true)
  return () => window.removeEventListener('keydown', handler, true)
}, [isActive, onClose, selectedId])
```

## 风险与权衡

1. **数据质量**：40+ 条新增数据需按史实，避免 AI 编造。每条 summary 50-100 字、fullContent 100-300 字是巨大工作量
2. **summary 拆句渲染**：Task 2 弹窗用 `detail.split(/[。！？]/)` 简单拆段落，可能不够精确；可改用 `MarkdownText` 渲染（更灵活），但需 fullContent 是 markdown 格式
3. **弹窗图片**：每个条目都用 Bing 检索图，可能出现不相关的图（如"节气·立春"搜到冬天雪景）。可在 imageKeyword 里加 "Chinese calendar" 等修饰
4. **不重复已有信息**：新增条目要避免和已有 39 条标题重复（如不要再加一个"春秋战国"）
5. **本次范围**：只做弹窗 + 数据补全，**不做跨子分类关联**（"哲学→儒→人物"是三期）
