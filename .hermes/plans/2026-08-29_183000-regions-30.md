**Goal:** 新增第 13 个子分类 `geography-regional`（地域文化），按用户提供 2 页目录加 30 条地域文化条目。

### Task 3: 实测验证

**Objective:** Playwright 验证地域文化子分类有 30 条 + chip 显示正确。

**Files:**
- Create: `tests/verify-regions.mjs`

**Step 1:** 写 Playwright 脚本：

```js
import { chromium } from 'playwright'
const browser = await chromium.launch({ headless: true })
const page = await browser.newPage({ viewport: { width: 1440, height: 900 } })
await page.goto('http://localhost:5173/history/', { waitUntil: 'domcontentloaded' })
await page.waitForTimeout(1500)
await page.keyboard.press('Space')
await page.waitForTimeout(2500)

await page.locator('text=全传统').first().click()
await page.waitForSelector('text=地域文化', { timeout: 5000 }).catch(() => {})
await page.waitForTimeout(2500)

// 默认"全部"视图总卡片数
const totalCards = await page.evaluate(() => 
  document.querySelectorAll('[role="button"][class*="cursor-pointer"]').length
)
console.log(`默认全部卡片: ${totalCards}`)  // 期望 98

// 点"地域文化" chip
await page.evaluate(() => {
  const btn = Array.from(document.querySelectorAll('button')).find(
    b => /地域文化\s*\(\d+\)/.test(b.textContent || '')
  )
  if (btn) btn.click()
})
await page.waitForTimeout(500)
const regionCards = await page.evaluate(() => 
  document.querySelectorAll('[role="button"][class*="cursor-pointer"]').length
)
console.log(`地域文化卡片: ${regionCards}`)  // 期望 30

// 验证标题含"燕赵"/"齐鲁"/"岭南"/"巴蜀"
const titles = await page.evaluate(() => 
  Array.from(document.querySelectorAll('[role="button"]')).map(b => b.textContent || '')
)
const keywords = ['燕赵', '齐鲁', '岭南', '巴蜀', '三秦', '吴越']
const found = keywords.filter(k => titles.some(t => t.includes(k)))
console.log(`找到关键词: ${found.length}/${keywords.length}`)  // 期望 6/6

await browser.close()
```

**Step 2:** 跑测试，期望：
- 默认全部卡片 = 98
- 地域文化筛选后 = 30
- 6/6 关键词匹配

5. **超出 12 子分类**：chip 行可能略拥挤（13 个），但所有"全xx" 板块都用类似模式，应该 OK
