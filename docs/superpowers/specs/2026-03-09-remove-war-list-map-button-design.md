# 战争列表卡片移除地图定位按钮设计

## 目标
移除战争列表卡片右上角的“📍 在地图上定位 ↗”按钮。地图定位能力继续保留在战争详情页中。

## 修改范围
- 文件：`src/components/Wars/WarsOverview.tsx`
- 删除列表卡片信息行中由 `war.coordinates` 条件渲染的地图定位按钮。
- 保留详情弹窗及详情页相关的 `jumpToMap`、`onViewOnMap` 和定位入口。
- 不调整卡片的图片、标题、标签、描述、尺寸、颜色或其他布局。

## 验收标准
1. 战争列表卡片中不再显示“在地图上定位”按钮。
2. 点击卡片仍能打开详情弹窗。
3. 详情页中的地图定位入口仍可用。
4. TypeScript/Vite 构建通过。
