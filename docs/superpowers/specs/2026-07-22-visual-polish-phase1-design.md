# 视觉精致化 · 第一阶段(全局基础)设计文档

日期:2026-07-22
项目:历史探索者(History Explorer · React + Tailwind + Zustand)

## 目标

提升整体视觉精致度,方向为 **强化复古/古典历史感(A)+ 提升数据可视化质感(C)**,
落地策略为 **先夯实全局视觉基础,再铺到数据可视化(D)**。

本设计仅覆盖**第一阶段:全局视觉基础**。数据可视化组件(Timeline / RelationshipGraph /
StatCard / 地图标记等)的提升为第二阶段,待第一阶段验收后单独 brainstorm。

## 采用方案

**方案 3(混合)**:先做低风险的全局精调(色阶/字体/阴影/纹理),同时新增少量高价值
语义 token(表面层级、质感类),但**不强制重构现有组件**——新 token 作为可选升级项,
第二阶段再逐步套用。

## 设计细节

### 1. 配色系统精调

- **补齐 bronze 中间调**:新增 `bronze-200`(最浅,近羊皮纸高光)与 `bronze-800`(深锚点),
  让金铜色过渡更丝滑。现有 300/400/500/600/700 不变。
- **ink 注入暖调**:最深的 `ink-900` 等压入极小幅暖褐(±3~5 色值),让深色底像"旧墨/深褐木"
  而非纯黑。**不降低对比度**。
- **新增语义表面 token**(为后续埋点):
  - `surface-raised`(卡片浮起面,比背景亮一档带暖调)
  - `surface-sunken`(凹陷面,如输入框)
  - `hairline`(极细分隔线专用色,比 ink-600 更微妙)

### 2. 字体层次与排版

- **建立标题层级 token**(含字号+字重+字距+行高):
  - `display`(页面主标题):大号衬线 + 微收紧字距 + 适度字重
  - `heading`(区块标题):中号衬线
  - `subheading`(卡片标题):小号衬线
  - 正文/说明保持无衬线,保证可读性
- **衬线标题精调**:中文衬线适度增加 `letter-spacing`(古籍疏朗感),标题行高收紧显庄重。
- **数字等宽**:年份/统计数字统一 `tabular-nums`,补齐尚未应用处。
- **决策**:只做中文标题层级(A),**不**做中英混排展签式标题。

### 3. 质感与装饰(卡片/表面/分隔)

**决策:只做质感,不做具象装饰(C)** —— 跳过卷草纹/菱形等具象元素(避免廉价土气感)。

- **羊皮纸微纹理背景**:主背景加一层**极淡**噪点/纤维纹理(CSS 生成或超轻量 SVG,不用图片),
  若隐若现,不干扰内容。
- **典籍卡片质感**:新增 `.card-classic` 类 —— 暖调表面(surface-raised)+ 柔和边框(hairline)
  + 顶部 1px 内层高光(模拟纸张受光)+ 统一阴影档位。
- **统一阴影**:沿用现有 depth-1~4 体系,把散落的自定义阴影收敛到该体系。
- **极淡暗角(vignette)**:大页面四周极淡暗角,聚焦视线(博物馆射灯感),克制到几乎无感。

### 4. 实施边界与安全性

**改动范围**:
| 文件 | 改动 |
|---|---|
| `tailwind.config.js` | bronze-200/800、ink 暖调微调、surface/hairline 语义色、标题层级 token |
| `src/index.css` | `.card-classic` 质感类、羊皮纸微纹理、极淡暗角、装饰底线工具类 |

**安全原则**:
- 纯增量:新增 token/工具类,不修改现有 `bg-ink-*`/`text-bronze-*` 的值
  (除 ink 极小幅暖调微调,±3~5,不影响对比度/可访问性)。
- 不重构组件:现有页面自动继承色/字微调即变精致;质感类/纹理/暗角为可选升级项,第二阶段套用。
- 可访问性守住:文字对比度不降低,`prefers-reduced-motion` 不受影响。
- 零 TS 风险:纯样式层,不碰逻辑。

**验证**:改完跑 `tsc --noEmit` + `npm run build`,确认零错误、构建通过。

## 非目标(YAGNI)

- 不做具象古典装饰(卷草/菱形/印章)。
- 不做中英混排标题。
- 不在本阶段重构任何数据可视化组件(留给第二阶段)。
- 不改动任何业务逻辑、store、数据。
